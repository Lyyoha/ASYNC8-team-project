# 🍰 Sweet Workshop (Солодка Майстерня)

**Sweet Workshop** — це сучасний вебдодаток для справжніх поціновувачів
десертів. Проєкт дозволяє користувачам ознайомитися з асортиментом солодощів,
фільтрувати їх за категоріями та отримувати детальні дані про кожен продукт.
Сайт реалізований як Single Page Application (SPA) з використанням асинхронних
запитів до бекенду.

[**🔗 Жива сторінка проєкту (Demo)**](https://lyyoha.github.com/ASYNC8-team-project/)

---

## 🚀 Основні можливості

- **Інтерактивний каталог:** Перегляд карток десертів із динамічним
  завантаженням через API.
- **Розумна фільтрація:** Сортування за категоріями (італійські, французькі,
  класичні тощо).
- **Адаптивність:** Повна підтримка пристроїв (Mobile 320px+, Tablet 768px+,
  Desktop 1440px+).
- **Retina Ready:** Оптимізація зображень для екранів з високою щільністю
  пікселів.
- **UX/UI деталі:** Плавні слайдери (Swiper), лоадери та миттєві сповіщення
  (iziToast).

---

## 🛠️ Технологічний стек

- **Layout:** HTML5, CSS3 (Flexbox, Grid), методологія BEM.
- **Logic:** JavaScript (ES6+), асинхронні запити (Async/Await).
- **Bundler:** Vite.
- **Libraries:**
  - `Axios` — робота з HTTP-запитами.
  - `Swiper` — інтерактивні слайдери.
  - `Accordion JS` — створення інтерактивних розкривних списків (акордеонів).
  - `iziToast` — обробка помилок та сповіщення.
  - `modern-normalize` — скидання стилів.
  - `css-star-rating` — додавання зірок.
  - `choices.js` — це бібліотека для кастомних `<select>` елементів.

## 📂 Структура проєкту

```text
src/
 ├── js/        # Логіка додатку та API запити

```

## 👥 Командна робота

Наша команда працювала разом за методологією **Scrum**:

- **Team Lead:** Керував завданнями, проводив перегляд коду (code reviews) та
  відповідав за цілісність проєкту.
- **Scrum Master:** Організовував щоденні зустрічі (stand-ups) та стежив за
  дотриманням робочого графіку.
- **Розробники:** Відповідали за створення окремих UI-компонентів та секцій
  сайту.

## ⚙️ Встановлення та запуск

Клонувати репозиторій:

```bash
git clone https://github.com/Lyyoha/ASYNC8-team-project.git
```

Встановити залежності:

```bash
npm install
```

Запустити проєкт:

```bash
npm run dev
```

Проєкт створено в рамках навчання в GoIT (2026).
